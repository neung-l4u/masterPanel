L4U Booking System

Architecture & Feature Map

An internal appointment booking system for the Local For You Sales team — staff log in to schedule meetings with overseas shop clients, save records to the database, send email notifications, and automatically create Calendar Events via Make.com Webhooks.

Booking Steps

  • Step 1 — Business Info: Shop type, Country, State, Timezone, City
  • Step 3 — Schedule: Salesperson, Booked By, Presentation Language, Date (Vanilla Calendar), Time
  • Step 8 — Customer Info: Shop Name, Customer Name, Email, Phone, Mobile, Line ID, WhatsApp, Address, Comment
  • Step 9 — Review & Confirm

Models (PHP API)

  • load_all_sales.php — Load all Sales staff (teamID=3) with profile pics
  • load_sales_by_country.php — Load Sales by Country
  • load_available_times.php — Check available time slots for a Sales person
  • save_appointment.php — Save booking record to DB
  • ShopTypeModel.php — Shop type model class (getActiveShopTypes, getById, getOptionsHtml)

Post-Booking Actions

  • sendEmail() — POST to Make.com Webhook to send email to Sales & customer
  • bookCalendar() — POST to Make.com Webhook to create a Calendar Event
  • Redirect to booking_success.php

Version 1.2 Features

Technology Stack

Backend (PHP)

  • PHP + Session-based auth (session_start())
  • Custom db class — MySQLi wrapper (Prepared Statements)
  • JSON API responses (header('Content-Type: application/json'))
  • Model files accept input via $_POST / $_GET

Frontend

  • Tailwind CSS — Modern utility-first UI framework
  • Bootstrap Icons 1.11.3 — Icon library
  • jQuery 3.7.1 — AJAX + DOM
  • Select2 — Dropdown searchable (Sales, Time, BookBy)
  • Vanilla Calendar Pro — Modern date picker (replaces Flatpickr)
  • Luxon 3 — Timezone conversion (Customer TZ → BKK)

External Services

  • Make.com Webhook — send Email notifications
  • Make.com Webhook — create Calendar Events (iCal format)
  • Google Analytics (G-LGKDYHL23T) — Tracking clicks

Database

  • MySQL + MySQLi (custom db class)
  • Connection config in assets/db/initDB.php
  • assets/php/share_function.php — Shared utility functions
  • Table sale_appointment — stores bookings
  • Table staffs — staff information
  • Table sale_staff_availability — Sales work schedule
  • Table sale_staff_country — which countries each Sales person covers
  • Table tb_shopType — shop type categories

Select Salesperson (AJAX: load_all_sales.php) → Booked By → Presentation Language → Date (Vanilla Calendar Pro: today~+7d) → Time (displays customer time + BKK preview via Luxon)

POST → save_appointment.php → DB
Calls sendEmail() + bookCalendar() simultaneously

JS GET /models/load_available_times.php?staff_id=X&date=Y
  |
  v  resolve day of week from date (Monday / Tuesday / ...)
  v  query sale_staff_availability WHERE staff_id = X AND day_of_week = ?
  v  query sale_appointment WHERE staff_id = X AND meeting_date = Y (already-booked slots)
  v  generate 15-minute slots between start_time → end_time
  v  filter out slots that exist in used_times
  v  return [{id: "HH:mm:ss", text: "HH:mm"}, ...]

JS POST /models/save_appointment.php
  |
  v  validate Request Method = POST
  v  receive: sales, shop_type, country, city, date, time, customer_name,
            shop_name, contact_email, contact_phone, line_id, whatsapp
  v  calculate end_time = time + 15 minutes
  v  map staff_id → staff_email (hardcoded map)
  v  INSERT INTO sale_appointment (...) VALUES (...)
  v  return {status: "ok"} or {status: "error"}

Integrations

Make.com — Email Webhook

URL: hook.us1.make.com/yk8yef5...
Sends a POST payload with full booking data. Make.com processes it and sends emails to Sales and the customer, including a Calendar link.

Make.com — Calendar Webhook

URL: hook.us1.make.com/hg8rqn...
Sends a POST with iCal datetime format (TZID:YYYYMMDDTHHmmss). Make.com creates a Google Calendar Event for the assigned Sales person.

Luxon — Timezone Conversion

Converts the customer's local time (manually selected Timezone per State) to Thai time (Asia/Bangkok) and shows a real-time preview, e.g. ⏰ BKK: 14:30 (Mon 02 Jun)

Google Analytics

Tracking ID: G-LGKDYHL23T
Automatically tracks click events via a Global Event Listener on elements with the data-ga attribute.

Staff Email Map

Hardcoded map in save_appointment.php and controllers/bookingController.js to resolve staff_id → email. Staff: boom, dear, honey, pluem, pruek, toffee, ball, lani, naya, gun, aon

Timezone per State

Supports 6 countries: AU, US, CA, UK, NZ, TH
Each country has States/Provinces with individual timezones, e.g. AU/QLD → Australia/Brisbane vs AU/NSW → Australia/Sydney
